# PolicyLens AI — Frontend

## Run

```bash
cd frontend
npm install
npm run dev
```

Open:

http://localhost:5173

The backend must be running on:

http://localhost:8000

## UI flow

Upload PDF
-> Analyze
-> Summary
-> Key policy details
-> Coverage / exclusions
-> Readability before/after
-> Critical fact validation
-> Original vs simplified
-> Policy Q&A
